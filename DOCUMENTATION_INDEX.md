## 🛠️ Project Summary Highlights

- **Framework**: React 18 + JavaScript + CSS3
- **Backend API**: Node.js + Express.js
- **Database**: MySQL 8.0 (Primary) + In-Memory Fallback Storage
- **Core Automation Engine**: Automated 15-day snapshot & periodic list generator
- **State Persistence**: Browser `localStorage` + REST Backend Database Sync
